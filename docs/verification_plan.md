# Verification (later)

Verification is part of the project, but these docs are mainly about **how the hardware works and why it is designed this way**.

We'll start with basic SystemVerilog simulations while building the cache. After the RTL is working, the longer-term plan is a UVM-style environment, scoreboard, assertions, and coverage. The [verification diagram](../diagrams/05_uvm_verification_environment.mmd) shows the intended components.

No test results or FPGA timing results are claimed yet.
